numbering (`CH3a-notes.md` ends at D177). Each settles a point the design leaves open or a shape

(`0e7382df80d`) from D216 (`v:N` = `validation.cpp` line N; `dbt:N` =

| D181 | **A repeated txid follows Core.** `add_from_block` queues every transaction but gives a txid already mapped no new map entry (`emplace`); eviction erases the front's txid from the map whichever entry holds it (`dbt:57`); removal takes the entry the map holds.
