# CH2b b3: subscribers (implementation plan and D-rows)

CH2b b3 is the last phase of PLAN row CH2b (`CH2-coins-flush.md` §7.2): `SubscriberHub` and `SubscriberDriver` under the
`SubscriberFeed` contract F1–F11, with SB5's `TipCell` as the producer (SB0 §12.1). The base is integration `6993f2f2f`.
The design is CH2 at that commit, read with its erratum E-b1. Core references are `v24.0.0-rc.3`: `v` is
`src/validation.cpp`, `ib` is `src/index/base.cpp`. Where this file and the design disagree, the D-row says why.
