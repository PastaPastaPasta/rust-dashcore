## 4. Notes

- Port 443 for Platform HTTPS (`IsAllowedPlatformHTTPPort`, evo/netinfo.cpp:59-66) is #7741 (02bcbc14957). It is in rc.2 and rc.3 already, so it is **not** an rc.3 → rc.4 delta. BL-393 lists it as post-rc.3.
- The Domain-entry decode (`NetInfoEntry::Unserialize`, evo/netinfo.h:243-263) is byte-identical at both tags. It reads a CompactSize length ≤ `DOMAIN_MAX_LEN` (253; `LIMITED_STRING` throws "String length limit exceeded"), then the bytes, then a big-endian u16 port. A short read or an oversized length throws out of the payload. A body that reads fully but is not a valid domain clears the entry, and reading continues.
- Hand-off from mn-overlay MN4-08 (#7839): received; CON. Its handling is in the report (§2, R18).
