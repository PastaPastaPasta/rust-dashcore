**SPORK_3 state is needed for SIG-12 and SIG-13.**
- If SPORK_3 is active on mainnet, v23 vs v24 differ only in the gap between leaving IBD and mnsync reporting blockchain-synced (ConnectBlock), plus the miner's sync requirement.
- If SPORK_3 is off on mainnet, v23 never rejects IS-conflicting blocks and the CL signer never checks IS safety.
- SP0 must pin the current mainnet SPORK_3 value. Do not assume the compiled default (4070908800 = off).

**Testnet interop (v24 profile).** v24 announces stable-txid AUs to peers below 70242 as (MSG_TX, stable txid). Such a peer computes the full hash, so its request tracker never matches; it rejects the tx anyway. This is harmless, but O12 mixed-version tests should expect it.

**Decode domain (BS4/BS11a).**
- BLS identity rejection (#7193) is identical on both pins: no profile split.
- New decode shape: CbTx v4 (+32 bytes after `creditPoolBalance`, read only when `nVersion >= 4`).
