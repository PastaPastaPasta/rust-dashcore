- **A1#7 corrections.** (1) "No longer caches true values" cannot be observed on mainnet. Both pins hard-code `GetSporkValue` there (every spork 0, SPORK_21 1), so a cached `true` always equals the recomputed value. Off mainnet it could differ only if adjusted or mock time goes backwards after a time-based activation, since v23 clears the cache only when a new spork message for that ID arrives, not on CheckAndRemove. That is not worth a profile field; treat it as INT. (2) GBT `superblocks_enabled` is kept in v24 as `true`. (3) On mainnet the multi-signer model is 1-of-1, so message acceptance and scores match.
