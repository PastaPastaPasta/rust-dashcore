| # | Decision | Why |

| D13 | **`dashd_net::torcontrol` holds Core's `TorController` without I/O, and a task that runs it as the `torcontrol` thread runs its event loop.** `TorController` takes the control port's lines and returns the commands to send; `TorHost` is what it changes (`SetProxy(NET_ONION)`, `g_reachable_nets.Add`, `AddLocal`/`RemoveLocal`) and reads (the key and cookie files, the nonce). The task connects, reads, and reconnects after `disconnected_cb`'s delay (1 s, ×1.5 in `float`, reset on connect). Like `event_base_dispatch`, it ends when nothing is left to wait for: a control port that cannot be looked up (at start or on a reconnection: Core schedules no retry, tc:139-149, :637-646), or a line over `MAX_LINE_LENGTH` (Core frees the connection without the disconnect callback, tc:113-119). Ending drops the controller, which withdraws the service (`~TorController`, tc:336-345). `Net::start` starts it at step 12 when `-listenonion` (default 1) on the first onion bind; `Net::interrupt` logs "tor: Thread interrupt" once, before the network's interrupt (init:290); `Net::stop` waits for it after `CConnman::Stop` (init:352). | One controller per node, on the network runtime; the sans-io half is what the unit tests drive. |
| D14 | **Core's quirks are kept.** Reply handlers and a half-gathered reply survive a reconnection (`Connect` frees the socket, not `reply_handlers`), so a reply on the new connection goes to the oldest handler. A reply's code is its final line's, `ToIntegral` (`-?[0-9]+`, else 0). The cookie is read up to 32 bytes (`ReadBinaryFile(path, 32)`), so a longer cookie file is cut and used. `-onlynet` is parsed again at each `GETINFO` reply, with `ParseNetwork`'s `tor` line. `-torpassword` wins over every method, and is sent with only `"` escaped. A connect refused (`ECONNREFUSED`, at once or later) or failing later is the error event: "Error connecting to Tor control socket", then the reconnection; libevent defers an immediate refusal's event (D20), so it is logged after "Reading cached private key".
