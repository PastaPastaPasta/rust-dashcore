### ND1 placement (OQ1; ND1-D27 accepts; D112)

- **Step 6** (network initialization, init.cpp:1649-1890): `p2p::Net::new` runs the identity and `-uacomment` checks and builds the network core, which loads `peers.dat` and the ban list. Its events are a cell bound at 7c (D113).
- **Step 7c** (Core makes and registers `PeerManager` after the 7b chainstate load, init.cpp:2194-2199): `Net::attach` builds P3's `Shared` (its queue starts `PreStart`), binds it as the core's events, and builds the `MessageLoop` and the listener. It registers the listener on V's queue through `Chain::signals()`. No seam: V has run nothing a listener must hear before step 11's ABC.
- **Step 12** (connman `Start`, init.cpp:2755): `Net::start` spawns `msghand` (`p3-net`, the `MessageLoop` over the host `ChainAccess`; a panic there calls `AbortNode`, D113), then `ConnMan::start`. A refused thread → `InitFailure::Exception`; `StartError::Bind` → `InitFailure::Error`; any other `StartError` → `InitFailure::Exception`.
- **`Interrupt`** (init.cpp:279-312, net.cpp:4144): message processing first (`Shared::interrupt`), then connman's (or, before step 12, the core's).
- **`Shutdown`**, after the RPC stop and before the scheduler stops, in Core's order (init.cpp:331-354):
  1. unregister the listener on the same `ValidationSignals` handle (init.cpp:347);
  2. close P3's queue, so a parked V resumes, then interrupt;
  3. **`StopThreads`** (net.cpp:4168-4185): join `msghand` first, where Core joins `threadMessageHandler`; then `ConnMan::stop_threads` (dial threads, accept loops);
  4. **`StopNodes`** (net.cpp:4187-4210): `NetCore::shutdown` writes `peers.dat` and `anchors.dat` if `Start` ran, deletes the peers, and dumps the ban list (`~BanMan`).

  Each part runs only for what init built (`Option`-gated; four node.rs tests, D113). `Drop` runs the same `stop` once, so a failed init leaves nothing running. The drop guard closes the queue on every actor exit (D32). V stops later, in `ChainSteps::shutdown`, so V serves until the actor has joined (§2.6).
