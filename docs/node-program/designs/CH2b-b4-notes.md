# CH2b b4: the node's production adapters (implementation plan and D-rows)

CH2b b4 builds the two adapters ND1 2b-2 waits on (`/work/scratch/nd1/plan-2b.md` M1, M2): CH1-node's `FlushSite`
over CH2b's `FlushControl`, W's `ThreadDriver` and CH3a's coins (M1), and V's `chain::BlockFiles` over ST2's
`dashd_store::flatfile::BlockFiles<F>` (M2). M3 (`ChainCommand::Flush`) is not b4's; M1 gives it its entry. The base is
integration `65ab30541`. Core references are `v24.0.0-rc.3`: `v` is `src/validation.cpp`, `bs` is
`src/node/blockstorage.cpp`. D-rows continue b3's (`CH2b-b3-notes.md`, D1–D53). "Item n" is CH1-node D47's adapter
contract.

b3's D13 and D25 already carry CH1-node D60 (every `DriverEvent` rings V's bell, `Released` too; 20d0622f7), so b4 has
no docs edit to fold in for them.
