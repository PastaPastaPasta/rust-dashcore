# GV1a: `dash-governance`, implementation D-rows

GV1a (PLAN line 696: `dash-governance` pure: hashes, validator, trigger format/parse, IsValid, best
SB, payments limit, tallies, rate buffer; M5; CON; FR-GOV-01, -02, -05, -06, -09) has no design
document. These rows record the implementer's decisions. Core references are to `v24.0.0-rc.3`
(`git -C ~/workspace/dash show v24.0.0-rc.3:<path>`); the oracle pin `77dbec8242` has the same
`src/governance/` except `superblock.cpp`'s StateDigest taps (O2a-GOV notes). In v24 the old
`governance/classes.cpp` and `validators.cpp` are folded into `superblock.cpp` and `object.cpp`.
Every public item names its Core function in a `// Core: file:line` comment.

Acceptance (binding): L0 Core's `proposals_valid` / `proposals_invalid` vectors; L1 `diff_gov`
and `diff_gov_vote` against the O2a-GOV oracle entries, each certified per DEC-184/186.
