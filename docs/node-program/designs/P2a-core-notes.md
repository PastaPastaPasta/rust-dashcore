# P2a-core: `dashd-p2p` implementation notes and D-rows

P2a-core implements `designs/P2a-outbound.md` rev3 (DEC-56) §7.2 phases A, C and E, reshaped by SB0 rev6.1 §3 and §12.1, on SB6's `dash-p2p`. This file records the implementer's decisions where those sources leave a choice, per the IMPLEMENTER contract ("decide, record a D-row, continue"). Core line numbers are the release tag v24.0.0-rc.3's (DEC-82) in every file of this leg; `np:` is `net_processing.cpp`. The pinned oracle's tree (`66c4e647…`) runs a few lines ahead of the tag in places, so a cite is checked against the tag.
