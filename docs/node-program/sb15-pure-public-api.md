# SB15 pure slices: additive API

The shipped sync and query paths keep using the legacy masternode engine.

- `dash_mnlist::ListView` adds `coinbase: Option<dash_consensus::primitives::TxRef>`.
- `dash_mnlist`, with `test-util`, adds `replay_rotated_capture(&[u8], ListDecoder) -> Vec<(LlmqType, QuorumHash, QuorumState, Commitment)>` and `ListDecoder = fn(&[u8]) -> Vec<SmlEntry>`, with `SmlEntry` (dash-evo's) re-exported beside it. The bytes are one gzipped rotated capture. The caller's decoder turns each of its evodb lists into SML entries, so dash-mnlist takes no normal dependency on dash-dml. Invalid fixtures panic. No member list is exposed.
- `dash_spv::ClientConfig` adds `clock: Arc<dyn dash_clock::Clock>` (system time by default) and `quorum_lookup_timeout: Duration` (10 seconds by default; `validate` refuses zero).
- `DashSpvClient::llmq_config()` returns the immutable per-client `Arc<LlmqConfig>` built at construction. Invalid chain parameters fail construction with `SpvError::Config`, before applying legacy global overrides.
- `dash_spv::client::anchor` exposes the unwired `InitialSync` driver (with `cand_gen()` and `coverage_rounds_spent()`), its `Phase` (`Establishing` and `Failed` included), `Input`, `Output`, `HeaderState` and `EstablishOutcome`. Reset outputs carry fresh Candidate metadata; the host executes durable store writes before constructing the chain. Inputs carry tip and candidate generations, and a coverage result from an older one is dropped. `HeadersCaughtUp` and `HeadersBehind` carry the `cand_gen` the host stamped on the chain that published them, and one from another candidate is dropped. `Input::Replaced { anchor, cand_gen }` reports a replacement the driver did not request; it makes a new candidate only when its `cand_gen` is newer, and while `Establishing` it waits for the outstanding result. `Covered` emits one guarded `Establish` with an `id`; only its result, matched by `id` and `cand_gen`, leaves `Establishing`, subscribers start only on `Established`, and a failed result emits `Output::FailStop` and enters `Phase::Failed`. With masternodes off the driver emits `Output::EstablishUnguarded` at open. The driver counts no attempts: the request pump owns every round and cooldown, and a spent round (`CoverageRoundSpent`) is counted for status and never retries or falls back. `Input::Opened` takes a `StoredChain`, read by `StoredChain::read` from a `HeaderStore`: an Established checkpoint anchor opens from the store's own window, every stored (header, hash) pair re-hashed, and a broken or corrupted window, or one below the DGW era's first anchor height (`StoredAnchorError::BelowDgw`), fails the open with `SpvError::StoredAnchor`. A Candidate whose pack is gone resets to a fresh candidate. An Established store that holds no record of any kind below its anchor (`HeaderStore::min_height`, context rows included) fails with `StoredAnchorError::LegacyAnchor`, which names wipe-and-resync; a window that lost its anchor's parent with lower rows still stored fails as `Broken`.
- `dash_chain::HeaderStore` adds the required `min_height()`: the lowest height of any stored record, active or not, from one index lookup. `NoStore` returns `None`; other implementors must add it.
- `dash_spv::client::mn_status` exposes the masternode owner's contract: `MnStatus` (published after each input that moves `gen`, `lookup_waits` or the snapshot), `MnCommand`, `Resolved { Answer, Asked, Busy }` and `MnHandle`.
- `dash_spv::client::quorum_lookup` exposes `QuorumQuery`, `QuorumLookupEngine` (`status()` and `resolve(query, reask)`, implemented by `MnHandle`) and `QuorumLookupBridge`. The bridge returns the engine's verified `FoundQuorum`, distinguishes not found from unavailable errors, waits on the owner's status for fetches, capacity and progress, and limits unavailable re-asks to one per query and one per type/hash per published tip. Each lookup is checked and registered in one owner step (`MnCommand::Resolve`); there is no separate tip call. The client query methods are not wired to it yet.

The C ABI gains one error code, `FFIErrorCode::LegacyAnchorError = 9`, for `StoredAnchorError::LegacyAnchor`; every other `SpvError::StoredAnchor` maps to `StorageError`. The new configuration fields require updating exhaustive Rust struct initializers.
