DEC-219's 150 GB launch check is neither a reservation nor a check at this step, so it does not close r2 Major 3. **Fix:** account for a serial run as one 28 GiB reservation under the same lock. When no slot fits, wait and retry or fail explicitly; do not start an unreserved serial run when the lock or reservation write fails. Keep its reservation until the step and its cleanup finish.
