# O2a-GV review (Sol r1)

**Verdict: CHANGES REQUIRED.** The payment and credit-pool rules match the inspected Core v24 paths, but two eager checks turn Core rejections into oracle context refusals.

1. **High — Preserve ConnectBlock's value-check short circuit.** [oracle.cpp](/work/home/agent/workspace/dash-wt/o2a-gv-oracle-v24.0/src/test/oracle/oracle.cpp:4542) calls `IsBlockPayeeValid()` even when `IsBlockValueValid()` returned false. Core [validation.cpp](/work/home/agent/workspace/dash-wt/o2a-gv-oracle-v24.0/src/validation.cpp:2846) immediately returns `bad-cb-amount` in that case. At a post-DIP3 regular height, a coinbase above the block reward and an absent tip list therefore have a definite Core verdict, but the shim's unnecessary payee read bootstraps a missing list and [WithContext](/work/home/agent/workspace/dash-wt/o2a-gv-oracle-v24.0/src/test/oracle/oracle.cpp:1390) returns `ORACLE_E_CONTEXT`. The eager payee-reward preflight at [oracle.cpp](/work/home/agent/workspace/dash-wt/o2a-gv-oracle-v24.0/src/test/oracle/oracle.cpp:4513) can similarly refuse before Core's amount verdict. **Fix:** return the amount rejection before payee checks, payee reward guards, and optional output computation; mark payee/output fields as uncomputed on that path. Add an overpay-without-list regression test.

2. **Medium — Defer the credit-pool window requirement until Core needs the window.** [oracle.cpp](/work/home/agent/workspace/dash-wt/o2a-gv-oracle-v24.0/src/test/oracle/oracle.cpp:4620) requires the window-start disk block before running the diff. `CheckCreditPoolDiffForBlock()` uses the seeded parent pool, then can reject an asset unlock (for example, `failed-creditpool-unlock-too-much`) in [creditpool.cpp](/work/home/agent/workspace/dash-wt/o2a-gv-oracle-v24.0/src/evo/creditpool.cpp:376) without reading the distant block. Core's check returns that reject; the shim returns `ORACLE_E_CONTEXT` when the window block is absent. The distant read occurs later in `GetCreditPool(next)` at [creditpool.cpp](/work/home/agent/workspace/dash-wt/o2a-gv-oracle-v24.0/src/evo/creditpool.cpp:195). **Fix:** run the diff/check first and require the window block only before accepted-path pool construction, retaining the unconditional requirement on that path so the process-wide cache cannot make results depend on call history. Test a rejecting unlock with an absent window block.
